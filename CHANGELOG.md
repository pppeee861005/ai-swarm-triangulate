# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-02

### Added
- Initial release of Triangulate Agent
- Three-dimensional analysis framework (Chip, Fundamental, Technical)
- Dynamic weight adjustment based on market conditions
- Fraud detection system with 4 validation checks
- Complete API for all dimensions and validators
- 3 comprehensive examples (basic, advanced, integrated)
- Full documentation with story and architecture guides

### Features
- Real-time multi-dimensional signal analysis
- Consistency verification across dimensions
- Liquidity trap detection
- Technical fake-out identification
- Chip anomaly detection
- Dynamic weight calculator
- Confidence scoring system
- Analysis history tracking

### Architecture
- Modular dimension-based design
- Extensible fraud detection framework
- Clara-based (Claude API) decision making
- Node.js 16+ compatibility
- Support for multi-market analysis (TW, US, HK)
